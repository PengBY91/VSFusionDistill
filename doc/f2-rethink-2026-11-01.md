# F2 思路调整（2026-11-01）

本页记录 E01–E10 之后对 F2 主线的一次复盘：哪里走偏了，为什么会走偏，接下来怎么改。它取代原来的代码库选型方案页（已删除，其中仍有效的事实并入本页第 6 节），并且是 `doc/experiments.md` §4 路线图的依据。选题草案 `topic-f2-degradation-robust-fusion-detection-distillation-2026-10.md` 的研究问题不变，变的是测量平台、判定对象和实验顺序。

## 1 现状一句话

工程和流程是扎实的，但 S0-lite 平台（UXO sample，5 条录音、单种子）上测出来的东西已经不是 F2 要回答的问题。E10 的正读数来自相机支路在单条录音上的类别排序变化；F2 真正关心的声呐支路，从 E04 到 E10 一直停在地板上（blob AP50 0.001–0.01），RQ-0、RQ-1、RQ-2、RQ-4 都没有被测到。

## 2 问题清单

### 2.1 数据结构：类别与录音完全绑定

sample 的 5 条录音每条恰好一个类别，训练集里每类只有一条录音（180722=cat1、105856=cat3、123500=cat2），测试集两条（100927=cat3、124735=cat2）。训练时"类别"和"录音外观"是同一个变量，分类头学到的大概率是"这是哪条录音"。跨录音类别泛化等于每类一个样例的迁移。

E08 起被称为"第一瓶颈"的类别轴，主要是这个划分造成的，不是任何方法能修的东西。E10 的增益也正好落在这里：test 相机分数实际只来自 100927（全 cat3），124735 是结构性 0；M3 把 cat3 预测从 145 条推到 224 条，cat2 仍以 1437 条压倒性主导，类无关 AP 反而降 0.021。教师自身就偏 cat3（cat2:cat3 = 1078:793）。在这个结构下，"score KD 传递清晰视角特权"和"score KD 搬运教师的类先验"无法区分。

### 2.2 测量仪器没先定动态范围

我们一开始就把测试放在跨录音划分上，没有先测同分布的天花板，也没有测种子间噪声。后果是：

- 所有声呐读数落在地板上，分不清"方法无效"和"仪器测不到"。
- E09c 和 B3 配置接近，相机 d3 读数差 0.020（0.0222 vs 0.0424），单种子跑间差大约就是 ±0.02，和 E10 判据 1 的阈值 +0.02 同量级。E10 的 +0.0434 没有种子复检。
- M3 相机保留率 R = 1.12 > 1（d2 最高），T-L 倒 U（d3 最高）。相机越模糊分数越高，说明这个指标主要在量类别排序（模糊压掉错类虚警），不是在量退化鲁棒性。

### 2.3 地板读数被当成了结论

E07 自己写过"检出处于地板时相关性指标无信息量"，但后面的表述逐渐把地板读数当结论用："融合在 S 规格下不构成声呐侧增益来源""RQ-0 互毒害分支未触发""声呐无伤害"。声呐双头 0.0098/0.0093 和 B0 0.0066 都在地板上，这些读数既不能支持"无伤害"，也不能支持"无毒害"。G0 闸门的真实状态是不可测，不是通过。

### 2.4 判定对象从声呐支路滑到了相机支路

F2 的核心机制（草案 Q5）是：教师看清晰相机，学生的相机退化，学生没法从自己的相机复现教师判断，只能去声呐里找线索，所以声呐支路被增强。E10 的主判据却读相机支路 AP。原因不难理解：只有相机支路有信号，于是判据跟着信号走。但"清晰图教师蒸馏退化图学生、提升退化图检测"是低照度、雾天检测里的成熟做法，不是 F2 的新颖点。

### 2.5 E10 的蒸馏路由本身就送不进特权信息

这一条是本次复盘新找到的，比数据问题更根本。M3 的路由是 camera←camera、sonar（融合头）←sonar、sonar_uncoupled←sonar，也就是声呐头只向教师的声呐头学。教师的声呐融合头要携带相机信息，前提是融合模块真的用上了相机特征；E09c 显示融合头和解耦头读数几乎相同（类无关 0.072 vs 0.077），对相机退化逐档零敏感，说明融合几乎没有用相机。若教师也是如此，教师声呐头输出的就是声呐自身的知识，sonar←sonar 蒸馏传的只有容量收益，没有特权收益。

现有代码里唯一跨模态的通道是 L_xp（`cross_plane_mil.py`），它只传 objectness，不传类别。如果光学的价值主要在类别（光学外观比声呐回波斑好分得多），那么现在的实现里没有任何一条路能把光学的类别知识送进声呐头。

### 2.6 精力被干扰轴吸走

E04–E09 的大部分时间花在"录音级域移位"上。这是 5 条录音之间外观差异带来的干扰，不是 F2 的自变量（F2 的自变量是相机可靠性 s）。只要测试落在域外地板上，s 轴上的任何效应都测不出来。

### 2.7 流程层面的几个口子

- 闸门没过时选择了放宽（E10 门 0 改为相对门），结论措辞却没有相应降级。
- test 录音被反复用于诊断和定参（台账承认是开发集性质），LOO-CV 工具写好了没有用。
- 消融顺序倒了：在噪声未知、主效应未复检时就跑 τ ∈ {1, 4}。
- 不少 bug 是事后由审查发现的（别名、KD 不反传、抖动空操作），说明评测仪器缺少"已知答案"测试。

## 3 调整后的思路

### 3.1 研究问题不变，主假设收窄

草案的 RQ-0 到 RQ-5 保留。结合 UXO 的实际情况，把 Q5 的"声呐支路被增强"收窄成一条可直接检验的假设：

> **H-cls**：在单目标水池场景里，声呐的定位本来就不难（文献同分布 AP50 约 0.94），声呐的短板在类别判别。光学模态能提供的特权信息主要是类别。因此特权蒸馏对声呐支路的增益应主要表现为声呐**类感知 AP 与类无关 AP 之差**的缩小，并且只有当蒸馏通道是跨模态的（教师相机 → 学生声呐）时才会出现。

这条假设有两个好处：它直接利用了 E08–E10 反复看到的现象（定位已通、类别塌缩），又给出了一个能被证伪的预测（同模态路由 sonar←sonar 不应产生类别增益）。

### 3.2 先修仪器，再测方法

顺序定为：同分布天花板 → 跨录音水平 → 种子噪声 → 方法效应 → 归因 → 超参数。每一步不过，不进下一步。

- **天花板**：同分布（同录音时间块留出）的声呐 AP50 应接近文献水平。达不到说明管线或标签有问题。
- **跨录音水平**：决定 UXO 能不能承载声呐主线（第 3.5 节三条路线）。
- **噪声**：每个判定都以 3 种子标准差 σ 为尺子，效应阈值取 max(2σ, 0.02)。

### 3.3 换数据平台：全量 UXO + 类别均衡的录音级划分

sample 的 5 条录音解不开类别和录音的绑定，只有全量数据（约 100 条轨迹、7.4 万帧、3 类）能解。具体做法：

- 录音级三分 train / val / test（约 6:2:2），按类别 × 几何（弧线/直线/瞄准模式）分层，保证每类在 val 和 test 中都有多条录音。
- val 用于一切开发期判定；test 在方法协议冻结前不开封，只评一次。
- sample 的 5 条录音已被当作开发集用过，一律放进 train 或 val，不进 test。
- 目标运动的录音（如 124735）打标记，分开报告。
- 每条录音按时间均匀采样封顶，避免长录音主导。
- 另留一个同分布留出集（train 录音的时间尾块，中间隔一段不用），专门量天花板。

细则和判定标准见 `doc/experiments.md` E11。

### 3.4 修正蒸馏通道：加一条跨模态类别路由

为检验 H-cls，需要一条把教师相机的类别分布送到学生声呐头的通道。UXO 有 π（`pairs.csv` 的跨模态对应），blob 门控帧上的声呐框位置可信，所以可以做对象级的跨模态类别蒸馏：对每个配对目标，在学生声呐头对应位置（blob 框内的正样本格）上，用教师相机头在配对相机框上的类别分布做软目标。这和 CMOLD 的做法同类（相机教师 → 声呐学生），区别在于我们的学生同时带退化相机输入，并且在 s 轴上扫描。

对照设计：

| 臂 | 声呐头的蒸馏来源 | 预期（H-cls 成立时） |
|---|---|---|
| 无 KD | — | 基线 |
| 同模态 | 教师声呐头 → 学生声呐头（E10 路由） | 类别差距基本不变，只有容量收益 |
| 跨模态 | 教师相机头类别 → 学生声呐头（经 π） | 类感知 AP 上升、类无关 AP 不变 |
| 类先验对照 | 不蒸馏，只把训练类先验调成教师的预测类分布（logit adjustment） | 若与跨模态同幅，说明增益只是类先验搬运 |

类先验对照是这次复盘最想补上的东西：任何蒸馏带来的类别增益，都要先排除"只是把类先验挪了个位置"。

另外加一个零成本的诊断：在教师上比较融合声呐头和解耦声呐头的类别分布差异。差异接近 0，说明教师的融合头里没有相机信息，同模态路由在原理上就传不了特权。

### 3.5 E11 之后的三条路线

E11 用 B0 在 val 上的跨录音声呐类感知 blob AP50（3 种子均值）给平台分档：

| 档位 | 读数 | 路线 | 含义 |
|---|---|---|---|
| 中间带 | 0.15–0.85 | A | UXO 能承载 F2 声呐主线；按第 4 节推进 E12、E13 |
| 天花板 | > 0.85 | B | 声呐几乎没有提升空间。UXO 只承载相机支路退化鲁棒性和 RQ-4 相关性；声呐特权主张等 RSFusion 或 H1。可以试困难子集，但要先预登记子集定义 |
| 地板 | < 0.15 | C | 全量下跨录音域仍然主导。F2 在 UXO 上暂停，域泛化单列为另一个问题；是否改用 CMHD 式同池划分由用户和指导人决定 |

路线 B 和 C 都意味着论文定位要变，需要用户和指导人拍板，不在实验台账里自动执行。

### 3.6 RQ-4 提前

支路误差相关性（RQ-4）是 F2 和"又一个融合检测器"最大的区别，而且只评不训、成本最低。它唯一的前提是两条支路都脱离地板。路线 A 或 B 一旦成立，就在已有模型上把相关性表跑出来，不必等 2×2 归因做完。

## 5 流程规则（补充到台账 §6）

1. **主终点按 RQ 固定**，写在本页而不是写在单个实验里：RQ-0、RQ-1、RQ-2 的主终点是声呐支路（融合头与解耦头）在 val 上的类感知 blob AP50；相机支路只作辅助读数。
2. **地板规则**：读数低于 0.05 或不足 3σ 时标"不可测"，不得用来支持"无效应""无伤害""无毒害"。
3. **闸门没过就重议，不放宽**。确需偏离时，结论层级自动降为"方向性"。
4. **单种子只出方向性读数**。判定类结论至少 3 种子。
5. **类别增益必须配类先验对照**，pooled 数字必须配逐录音、逐类分解。
6. **先噪声、再主效应、再归因、最后超参数**。
7. **评测仪器要有已知答案测试**：完美预测得 1.0、全错类得类无关 AP 不变而类感知为 0、类先验平移的预期变化等，进 `tests/`。

这七条管"怎么判"。推进期"怎么干"的操作纪律见第 8 节（2026-11-02 补记）。

## 8 实施纪律：推进期如何坚持主线（2026-11-02 补记）

第 2 节列的走偏方式，没有一种是单点决策错误：类别与录音绑定是数据现实，判据滑向相机支路是因为只有相机有信号，τ 消融先跑是链已经挂上。每一步都局部合理，加起来偏离主线。所以防的不是错误决策，是"无人把关的默认前进"。本节把已经发生过的每种走偏各对应一条可执行机制，E11 起生效。主线的唯一定义是本页第 3、4 节加台账第 4、6 节；定义之外的想法一律先记待办，不直接开训。

**机制**（每条括注对应的走偏来源）：

1. 立项三问：这个任务回答哪个 RQ、在第 4 节路线表的哪一行、前提是否满足。三问答不上就不立项、不开训。τ 消融若在立项时过这三问，会在"噪声未知"处被拦下（§2.7）。
2. 闸门制推进：以闸门为单位，不以日历为单位。每个 E 编号启动前过准入核对（前置项、预登记、预算），收尾过准出核对（判据逐条过账、产物入账、台账 §0 与 README 状态同步）。上一步产物未入账，不开下一步。E11 的数据闸门 0 是模板，推广到所有编号。
3. 出数先抄判据表：实验出数后第一件事是把预登记判定标准逐条过账；预登记之外冒出的读数只进"记录不判定"栏。相机支路再亮眼也不改声呐主终点（§2.4 的教训）。
4. 无人值守链的生存规则：链上每步完成落 .ok 标记；任一步重试两次失败即停链报警，不许静默降级或换姿势再试；链启动后十分钟内人工确认一次进度。2026-11-02 的 tau4 事故里，GPU 因同一技术点空转近五小时无人察觉，缺的就是这三条（`doc/logs/2026-11-02-tau4-resume-weights-only.md`）。
5. 没执行过的路径先冒烟：resume、D∞ drop、按 split 评测这类此前未在真实链上跑过的路径，先做 1 epoch 或小样本冒烟，再挂长链。tau1 一次跑完 100 epoch，resume 路径等于从没测过；E11 的三臂 × 3 种子长训练必须用 resume，此路径须先有测试（同上事故记录的待办一）。
6. 支线时盒：诊断、文献、工具改造类工作（如教师 T-L 融合头类别分布诊断）设时盒，超时挂起记入待办。判据只有一条：它是否阻塞主线下一闸门；不阻塞就排在后面。
7. test 不开封落在命令行上：E11 期间所有评测命令显式 `--split val`（前置项 5 已支持逐 split 输出），test 路径不进任何命令历史，直到协议冻结。
8. 文档同步点：出数 24 小时内入账五段式；E 编号关闭时同步台账 §0、§4 与 README 第 9 节；README 中的测试计数等数字随提交更新。2026-11-02 整理时发现 README 落后两个提交（测试数 161 对 207、前置项状态陈旧），即为缺此机制的实例。
9. 复盘触发器：不等大事故。出现以下任一情形即暂停，对照第 2 节自查：连续两个实验读数在地板；判定阈值与 σ 同量级；有人在出数后提议改判据；链上重试达到两次；新增实验没有一个推进路线表下一行。

这些机制的代价是启动慢一点，换的是不再用六个实验才发现平台测不了主线。允许偏离，但偏离必须在对应实验节写明原因并降级结论层级（与第 5 节规则 3 同构）。
