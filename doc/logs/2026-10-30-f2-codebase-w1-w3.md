### 关键设计决定（当日新增，超出方案页已记录范围的）

1. D∞ 训练期=黑帧（`dinf_mode="zero"`），测试期=丢弃（`"drop"`）：
   训练按 p(s) 逐样本抽 D∞（0.2），若按"丢弃"实现，batch 内混合 None/图像
   无法组张量；整批丢相机又会让融合支路 80% 的 batch 失效（bs=8 时
   P(整批有相机)≈0.8^8≈17%）。黑帧=物理上"无光到达传感器"，与 D∞ 语义一致，
   batch 保持稠密。测试 batch=1，逐样本真实丢弃。预处理器对含 None 的 batch
   整批降级为相机缺失；`CrossAttnFusion` 在无相机特征时退化为
   `sonar_proj(sf)`（残差分支去掉注意力项，通道一致），`ConcatFusion` 显式报错
   （它无法回退，只能配 zero 模式使用）。
2. 声呐输入=极坐标矩形图（aris_raw 方位展开，x=方位角升序）。依据：
   读 `uxo-dataset2024` 的 `prep_2_aris_to_polar.py` 确认 aris_polar 是扇形
   （rays 从底部中心发散，列不恒方位），与 L_xp 的"列→方位窗"实现冲突；
   团队声呐只能输出图像，矩形图与真实声呐图像形态一致。`sonar_zero_centred=True`
   （ARIS 方位 0° 居中），同步翻转合法。
3. 类别索引=GT json categories 的文件顺序枚举（`PairedSonarCameraDataset`
   与 `tools/test.py` 同一映射），不按 id 排序；评测时 image_id 直接由
   frame_meta 列写入 DetDataSample metainfo（`coco_image_id`），预测文件无需
   反查。
4. `read_paired` 归一 CSV 类型（id 列 int、sample_id str），消除
   "5" vs 5 的跨源比较错误（当日实际踩到）。
5. **mmengine 细节**：`Config.fromfile` 自身处理 `custom_imports`（须先保证
   仓库根在 `sys.path`）；`BaseDenseHead.predict` 返回 list[InstanceData]，
   需经 `BaseDetector.add_pred_to_datasample` 包装；序列化数据集
   （`serialize_data=True`，Runner 默认）会清空 `data_list`，须走
   `get_data_info(i)`；根级 `test_dataloader/test_cfg/test_evaluator`
   三者须同置（占位 `TestLoop`+`DummyMetric`）。

## W1 验收（COCO 复现）与 YOLOX 预处理坑（2026-10-30）

首跑 AP=0.004（全面崩塌）。逐层排查：ckpt 为真 300-epoch mmdet 2.18
训练权重（meta 带 `best_score 0.403`），462 键名+形状与模型全等、
`load_or_resume` 确认加载、输入张量数值正常，但 obj 分支 sigmoid
max≈1e-4、cls 勉强 0.5。根因：我生成的 val 配置给 YOLOX 配了
ImageNet mean/std + bgr_to_rgb，而官方 YOLOX 全程吃 0–255 BGR 原图
（mmdet2 pipeline 无 Normalize，mmdet3 `DetDataPreprocessor` 也不带
mean/std）。同时缺 `Pad(pad_to_square=True, pad_val=114)`，NMS/score
阈值也应为 0.65/0.01 而非通用默认 0.55/0.05。

修正 `tools/eval_coco_yoloxs.py` 生成的配置逐项对齐安装版
`configs/yolox/yolox_s_8xb8-300e_coco.py`；20 图子集 mAP 59.3 复活
（小子集方差大，仅作管线 sanity）。同一坑已同步修掉我们自己仓库的
`two_stream_yolox_s.py`（去掉 mean/std/bgr_to_rgb，YOLOX 分支从此
统一 0–255 BGR 约定；日后相机流用 COCO 预训练 YOLOX-S 初始化时直接
兼容）。参考精度按安装版 metafile 取 40.5（mmdet2 发布说明 40.2）。
1000 图全量验收结果见下。

### W1 COCO 复现验收通过（全量 val2017）

- 采样方式教训：按 id 排序的 first-1000 子集 AP 42.2（+1.7 偏高，

## UXO 声呐框投影标定（2026-10-31 完成，TODO 14.2 条目 4）

`aodet/datasets/converters/uxo_projection.py`：逐 recording 的三阶段稳健
标定：第一阶段相机方位拟合（静态链 12 种子 + look-at 种子网格，选 Huber

constant(0，直线)、aim(+2，操作员逐帧重新瞄准，Rodrigues 对齐)。
测距几何按官方 `BeamWidthsAris3000_128` 表（非均匀波束，±15°，128 列，
`aodet/geometry/aris_beam_table.py`），行 ↔ 斜距 window_start+r·Δ。

### P↔b 退化与处理

目标位于弧心附近（真实水池布局）时距离剖面几乎平坦，P_radial 与 b_rng
只靠先验区分；无界联合拟合会跑飞（10-30 旧代码在 100927 上 b=−16.3 m
即此症状，当时误当标定失败）。处理：`_SIG_B_PRIOR=0.25` 先验 +
`_B_RNG_MAX=0.8` 硬界（半目标长 0.6 m + 声速余量）。合成水槽测试按
可辨识性断言：弧线 |err_P|<0.15 m、|Δb|<0.08；直线放宽到 0.8/0.15（沿
路径位置与 b 交换）；联合距离预测 |P−s|+b 在所有几何下 rms<0.05 m。
瞄准工况含 0.4°/帧操作员抖动（常量失准模型未覆盖），dcol 门放宽到
6 beams，注释说明。9/9 通过；全套 74 测试绿。
