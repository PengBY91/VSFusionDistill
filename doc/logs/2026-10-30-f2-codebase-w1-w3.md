### 关键设计决定（当日新增，超出方案页已记录范围的）

1. **D∞ 训练期=黑帧（`dinf_mode="zero"`），测试期=丢弃（`"drop"`）**。
   训练按 p(s) 逐样本抽 D∞（0.2），若按"丢弃"实现，batch 内混合 None/图像
   无法组张量；整批丢相机又会让融合支路 80% 的 batch 失效（bs=8 时
   P(整批有相机)≈0.8^8≈17%）。黑帧=物理上"无光到达传感器"，与 D∞ 语义一致，
   batch 保持稠密。测试 batch=1，逐样本真实丢弃。预处理器对含 None 的 batch
   整批降级为相机缺失；`CrossAttnFusion` 在无相机特征时退化为
   `sonar_proj(sf)`（残差分支去掉注意力项，通道一致），`ConcatFusion` 显式报错
   （它无法回退，只能配 zero 模式使用）。
2. **声呐输入=极坐标矩形图（aris_raw 方位展开，x=方位角升序）**。依据：
   读 `uxo-dataset2024` 的 `prep_2_aris_to_polar.py` 确认 aris_polar 是扇形
   （rays 从底部中心发散，列不恒方位），与 L_xp 的"列→方位窗"实现冲突；
   团队声呐只能输出图像，矩形图与真实声呐图像形态一致。`sonar_zero_centred=True`
   （ARIS 方位 0° 居中），同步翻转合法。
3. **类别索引=GT json categories 的文件顺序枚举**（`PairedSonarCameraDataset`
   与 `tools/test.py` 同一映射），不按 id 排序；评测时 image_id 直接由
   frame_meta 列写入 DetDataSample metainfo（`coco_image_id`），预测文件无需
   反查。
4. **`read_paired` 归一 CSV 类型**（id 列 int、sample_id str），消除
   "5" vs 5 的跨源比较错误（当日实际踩到）。
5. **mmengine 细节**：`Config.fromfile` 自身处理 `custom_imports`（须先保证
   仓库根在 `sys.path`）；`BaseDenseHead.predict` 返回 list[InstanceData]，
   需经 `BaseDetector.add_pred_to_datasample` 包装；序列化数据集
   （`serialize_data=True`，Runner 默认）会清空 `data_list`，须走
   `get_data_info(i)`；根级 `test_dataloader/test_cfg/test_evaluator`
   三者须同置（占位 `TestLoop`+`DummyMetric`）。
